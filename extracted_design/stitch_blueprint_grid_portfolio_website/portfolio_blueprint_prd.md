# PRD: Neobrutalism Web Portfolio (Blueprint/Grid Edition)

## 1. Visual Design System
- **Background**: Off-white (#F5F5F5) with an electric blue thin-line grid pattern (blueprint style).
- **Borders & Shadows**: 3px-4px solid black borders. Solid, non-blurred drop shadows shifted bottom-right.
- **Typography**: Bold sans-serif (e.g., Space Grotesk, Archivo).
- **Accents**: High-contrast colors like electric blue or bright yellow for CTAs.

## 2. Screen List
1. **Home (Hero)**: Massive greeting, 2-column layout, profile photo with "tape" stickers.
2. **About**: Introduction about Rejang Lebong origin, logical approach, 2-column with candid photo.
3. **Experience**: Vertical timeline with alternating cards on a central "stem".
4. **Education**: Parallel 2-column layout with large cards for High School and University.
5. **Projects**: Showcase of exactly 3 projects with thumbnails, tech stacks, and links.
6. **Tech Stack**: Infinite marquee of tools (HTML, CSS, Tailwind, JS, Astro, React, Prisma, Git).
7. **Contact & Footer**: Bold form fields and a high-contrast full-width send button.

## 3. Navigation
- Sticky navbar with solid white background and thick bottom border.
- Menu: About, Experience, Education, Projects, Contact.
